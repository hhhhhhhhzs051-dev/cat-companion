# 下载与第一次试用

适用于 **macOS 14 或更新版本**，界面和默认短句为中文。Windows、iPhone 和 iPad 不支持这个原生桌面版。Apple Silicon 与 Intel 包含在同一个通用包里；Intel 实机和另一台 Mac 的首次安装尚未验证。

## 下载并安装

1. 打开 [GitHub Releases](https://github.com/hhhhhhhhzs051-dev/cat-companion/releases)。展开版本下方的 **Assets**，寻找 `Cat-Companion-Open-Source-macOS-manual.zip`。如果还没有这个文件，目前只能[从源码构建](BUILDING.md)。GitHub 自动生成的 **Source code (zip)** 是源码，不是可双击运行的安装包。
2. 下载同一版本的 `SHA256SUMS.txt`。可在终端进入下载目录后运行 `shasum -a 256 -c SHA256SUMS.txt`，确认 ZIP 显示 `OK`。校验和用于检查下载是否完整，不等于 Apple 公证。
3. 双击 ZIP 解压，把 **Cat Companion Open Source.app** 拖到 Finder 的“应用程序”文件夹，再从那里打开。不要直接运行 ZIP 内的程序，也不要修改 app 内部文件。
4. 当前预览包只有本地临时签名，**尚未经过 Apple 公证**。如果 macOS 阻止打开，先核对来源和版本，再参考 [Apple 官方打开说明](https://support.apple.com/en-gb/102445)：在“系统设置 → 隐私与安全性”查看对应应用的提示，仅在信任此包时选择“仍要打开”。若提示包含恶意软件、损坏或无法验证完整性，停止打开并报告问题。不要关闭 Gatekeeper 或运行解除隔离脚本。

## 第一分钟可以试什么

| 操作 | 预期结果 |
| --- | --- |
| 点一下猫头 | 短暂闭眼回应 |
| 在头部或背部按住并轻轻移动 | 出现抚摸反馈，松手后逐渐恢复 |
| 拖动蓝绿色猫窝 | 移动猫咪的位置 |
| 右键点击猫咪，选“拿出小绒球” | 出现小球，可以按住拖到猫爪附近，再松手 |
| 打开同一菜单的“成长小窝” | 查看每日互动目标和本机成长进度；奖励需要积累，不保证首次试用即解锁 |
| 选择“给你的一封信” | 打开公开版附带的示例信件 |

菜单还可以调整大小、回到屏幕角落和设置“窗口置顶”。全屏应用和其他桌面空间不一定显示猫咪。选择“退出猫咪陪伴”可完全退出；“收起桌面猫”只是隐藏。

[查看动作演示及其生成方式](DEMO.md)。演示使用公开版渲染代码，不含私人桌面或存档。

## 常见问题

- **没有看到猫**：检查是否已选择“收起桌面猫”；从菜单栏的猫咪入口选择“显示桌面猫”，或在“设置”里选择“回到屏幕角落”。
- **小球或动作没有反应**：先检查是否处于“休息一下”状态，必要时选择“继续陪伴”；减少动态设置也会限制部分动画。
- **只下载到一堆文件**：这是源码包，请回到 Releases 的 Assets 找应用 ZIP，或按构建说明操作。
- **想更新**：先退出旧版，保留本机数据，再用同名新 app 替换“应用程序”中的旧 app。不要删除 Application Support 目录。升级后的兼容性以相应版本说明为准。
- **想卸载**：退出后把 app 移到废纸篓。本机记录会保留在 `~/Library/Application Support/local.catcompanion.opensource/`；只在确定不再需要时自行删除。开源版与私人版采用不同应用标识和数据目录。
- **遇到问题**：到 [Issues](https://github.com/hhhhhhhhzs051-dev/cat-companion/issues/new/choose) 提供 macOS 版本、芯片类型、应用版本、复现步骤及预期/实际结果。截图前遮住私人桌面、信件和姓名，不要上传真实存档。

当前预览是实验性手动安装版本。另一台 Mac、Intel 实机、长期和多屏使用均需进一步验证；不把本机测试通过当作这些场景已经验证。
