# Reporting security and privacy issues

Do not put credentials, personal letters, save files or private screenshots in public issues. If GitHub private vulnerability reporting is enabled for the repository, use its Security tab. Otherwise contact the maintainer through a private contact method listed on their public GitHub profile; do not assume a private reporting channel exists until it is configured.

This is an early source distribution with no paid support or response-time commitment. Scope includes unintended disclosure of local text, unsafe file handling and unexpected network activity. Ordinary interaction bugs belong in a sanitized issue.
